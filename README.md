# -Focus-up---A-Smart-Study-Timer

Install Dependencies for Backend:
Goto your file path and open CMD.

npm install express mongoose cors bcryptjs jsonwebtoken

Run above one in your cmd.
And run server.js file in vscode.

To see data stored in Mongodb:
First register and login by running server.js file in vscode.
Open cmd through file path.
Type "mongosh".
Type "use timetableGenerator".
Type "show collections".
Type "db.collection_name.find()".
And your data will display.

Note : By default authentication password is hashed and salted using bcrypt for good security practice
